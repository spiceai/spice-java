# Spice Java SDK v0.8.1

## Fixes

### 🔑 API key Authentication

The client now accepts any API key that is not empty for [API key authentication](https://spiceai.org/docs/api/auth). ([#60](https://github.com/spiceai/spice-java/pull/60))

```java
try (SpiceClient client = SpiceClient.builder()
        .withApiKey("my-runtime-key")
        .build()) {
    // ...
}
```

- A key that the runtime rejects fails at once with `UNAUTHENTICATED`. The client does not retry it, and does not prepare a cached statement again with the same key.
